🦆 duck-vpn

Free VPN Gate servers, ranked by how likely they are to get past geo-blocks.

How to use this on iPhone
  1. Install OpenVPN Connect from the App Store (free).
  2. Pick a country below and tap Get on the top server.
  3. Open the downloaded file and choose OpenVPN, then tap Add and connect.
  4. If it won't connect, open OpenVPN Connect Settings → Security Level → Insecure (VPN Gate relays use older ciphers), or try the next server.

Servers are run by volunteers who can see unencrypted traffic. Use them for unblocking content, not for banking or logins you care about.
